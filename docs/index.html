Universe Civilization: Empire at Wars is a browser-based strategy game project featuring world development, orbital infrastructure, fleets, turn-based battles, covert operations, and a persistent game economy.

Hosting note: This GitHub Pages site is a static project portal and documentation site. GitHub Pages cannot run the PHP game server or connect to its MySQL database. Deploy the playable application separately using the documented container setup.
